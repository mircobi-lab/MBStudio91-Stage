# Collaudo Fase 1, sul MacBook Pro

Segna ogni prova con OK o con quello che è successo. Se qualcosa non va, annota il plugin, la tastiera e cosa stavi facendo.

| # | Prova | Esito |
|---|---|---|
| 1 | L'app si apre e mostra la finestra nera con la scritta MBSTUDIO91 STAGE. | |
| 2 | IMPOSTAZIONI AUDIO: scegli la scheda e il buffer. Chiudi e riapri l'app: la scelta è rimasta. | |
| 3 | SCANSIONA PLUGIN trova Sylenth1, DUNE 2 e almeno due plugin MBStudio91 (VST3 o AU). | |
| 4 | Ogni strumento suona dalla Keystation 88 MK3, dalla Launchkey 61 MK2 e dalle due Launchkey Mini. | |
| 5 | APRI PLUGIN mostra l'interfaccia del plugin. Con la finestra aperta cambia strumento dal menu: l'app non si chiude. | |
| 6 | Un effetto nello slot 1 si sente. VOLUME e MUTE cambiano il suono senza clic. | |
| 7 | Tieni qualche nota col pedale premuto e premi PANIC: silenzio immediato, nessuna nota resta appesa. | |
| 8 | Stacca e riattacca una Launchkey con l'app aperta: torna a suonare senza riavviare. | |
| 9 | Con un plugin caricato cambia la frequenza di campionamento nelle impostazioni (per esempio da 44,1 a 48 kHz): il suono resta intonato. | |
