# Collaudo Fase 4, Ableton Push 2

Il Push 2 risulta collegato al Mac mini: per questa prova spostalo sul MacBook, dove gira Stage.
**Chiudi Ableton Live prima di iniziare**: tiene occupata sia la porta MIDI su cui il Push ascolta, sia l'interfaccia USB del display.

Segna ogni prova con OK o con quello che è successo.

## Collegamento

| # | Prova | Esito |
|---|---|---|
| 1 | Apri Stage col Push collegato: i pad si accendono e il display mostra nome patch, postazioni e BPM. | |
| 2 | Apri Stage senza il Push, poi collegalo: si aggancia da solo, senza riavviare. | |
| 3 | Stacca il Push mentre Stage è aperto: niente blocchi, il resto continua a funzionare. | |
| 4 | Chiudi Stage e apri Live: il Push torna normale, con i colori di Live. | |

## Patch e banchi

| # | Prova | Esito |
|---|---|---|
| 5 | I 64 pad mostrano le patch del banco: la prima in alto a sinistra, come sullo schermo e sulla Launchpad. | |
| 6 | Un pad richiama la patch; quella attiva si distingue dalle altre salvate. | |
| 7 | Gli 8 tasti sopra il display cambiano banco. | |
| 8 | Colonna a destra: mute delle 4 postazioni, patch precedente e successiva, TAP. | |
| 9 | L'ultimo tasto a destra tenuto mezzo secondo fa PANIC. Un tocco breve no. | |
| 10 | Launchpad e Push 2 collegati insieme: si aggiornano tutte e due e si possono usare entrambe. | |

## Rotativi

| # | Prova | Esito |
|---|---|---|
| 11 | I primi quattro rotativi sopra il display muovono il volume delle quattro postazioni, e la manopola sullo schermo li segue. | |
| 12 | Il volume si ferma a +6 dB girando a destra e a −60 dB girando a sinistra, senza saltare da un estremo all'altro. | |
| 13 | Il rotativo del master muove il volume generale. | |
| 14 | In tempo libero (INT) il rotativo del tempo cambia il BPM; con il clock esterno (EXT) non lo cambia. | |
| 15 | Dopo aver mosso un volume, accanto al nome della patch compare l'asterisco di "modificata". | |

## Display

| # | Prova | Esito |
|---|---|---|
| 16 | Il display resta acceso anche quando non cambia niente (non si spegne dopo due secondi). | |
| 17 | Cambiando patch, il display si aggiorna subito. | |
| 18 | Con il solo cavo USB, LED e display sono più tenui: è il Push che si limita per stare nei 500 mA. Collega l'alimentatore e confronta. | |
