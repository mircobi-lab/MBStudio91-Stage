# Collaudo Fase 3, sul MacBook Pro

Collega le quattro tastiere e la Launchpad Mini prima di aprire l'app. Segna ogni prova con OK o con quello che è successo.

## Patch

| # | Prova | Esito |
|---|---|---|
| 1 | Prepara un suono su ogni postazione, seleziona un pad vuoto (Maiusc + clic) e premi SALVA. Dai un nome: il pad diventa ambra con il nome. | |
| 2 | Cambia qualcosa (un plugin, TRASP, un parametro di Sylenth1): accanto al nome compare l'asterisco. | |
| 3 | Richiama la patch con un clic: tutto torna com'era salvato, asterisco sparito. | |
| 4 | Chiudi e riapri l'app: la libreria c'è ancora. In `~/Music/MBStudio91 Stage/` c'è anche la copia del giorno `libreria-AAAA-MM-GG.xml`. | |
| 5 | RINOMINA, COPIA, INCOLLA su un altro pad e CANCELLA funzionano e chiedono conferma quando serve. | |

## Cambio senza buchi

| # | Prova | Esito |
|---|---|---|
| 6 | Tieni un accordo con il pedale e cambia patch: l'accordo continua, le note nuove suonano con la patch nuova, nessun buco. Rilasciando il pedale l'accordo si spegne, poi la coda sfuma. | |
| 7 | Cambia patch due volte in fretta: resta l'ultima, niente doppio suono. | |
| 8 | Seconda volta sulla stessa patch: il cambio è quasi istantaneo (i plugin sono già pronti). | |
| 9 | Disinstalla o rinomina temporaneamente un plugin usato in una patch: richiamandola, quella postazione mostra l'errore, le altre suonano. | |

## Launchpad Mini

| # | Prova | Esito |
|---|---|---|
| 10 | La griglia mostra le patch del banco: ambra salvata, verde attiva, rosso lampeggiante mentre carica. | |
| 11 | I tasti tondi in alto cambiano banco (verde attivo, ambra con patch). | |
| 12 | Tasti tondi a destra 1–4: mute delle postazioni (rosso), anche sullo schermo. | |
| 13 | Tasti 5 e 6: patch precedente e successiva, anche attraverso i banchi. | |
| 14 | Tasto 7: TAP, lampeggia a tempo. Tasto 8 tenuto mezzo secondo: PANIC. Un tocco breve non fa nulla. | |
| 15 | Stacca e riattacca la Launchpad con l'app aperta: torna a funzionare con i LED giusti. | |

## Tempo e uscita

| # | Prova | Esito |
|---|---|---|
| 16 | INT: cambia il BPM o batti TAP; l'arpeggiatore o il delay a tempo di Sylenth1/DUNE seguono. | |
| 17 | EXT con CLOCK DA su una drum machine o su Ableton: il BPM segue, Start/Stop fermano e ripartono gli arpeggi. Staccando il clock compare "CLOCK ASSENTE" e il BPM resta fermo. | |
| 18 | Volume alto su tutte le postazioni insieme: l'uscita non distorce in modo duro (limitatore). | |
