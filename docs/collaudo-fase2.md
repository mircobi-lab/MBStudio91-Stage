# Collaudo Fase 2, sul MacBook Pro

Collega tutte e quattro le tastiere prima di aprire l'app. Segna ogni prova con OK o con quello che è successo.

| # | Prova | Esito |
|---|---|---|
| 1 | Al primo avvio la Keystation risulta già sulla postazione 1 e la Launchkey 61 sulla 2, con il LED verde. | |
| 2 | Postazione 3: premi ASSEGNA, poi un tasto della Launchkey Mini MK2. Il nome compare e il tasto premuto non suona. Ripeti per la postazione 4 con la Mini MK1. | |
| 3 | Carica uno strumento diverso su ogni postazione: ogni tastiera suona solo il suo. | |
| 4 | I pad e le porte "DAW" o "InControl" delle Launchkey non fanno suonare nessuna postazione. | |
| 5 | Chiudi e riapri l'app: le quattro assegnazioni sono rimaste. | |
| 6 | Stacca una Mini con l'app aperta: il LED si spegne e il nome diventa grigio. Riattaccala: torna verde e suona. | |
| 7 | Mentre suoni, il LED della postazione lampeggia bianco. | |
| 8 | TRASP +12 sulla postazione 2: suona un'ottava sopra. Tieni una nota, cambia TRASP e rilascia: nessuna nota resta appesa. | |
| 9 | Split sulla Keystation: DA C-2 A B2 su una postazione. Le note da C3 in su non suonano. | |
| 10 | CURVA MORBIDA sulla Keystation: suonando piano il volume sale. DURA: serve più forza. PERSONALIZZATA: compare GAMMA e cambia la risposta. | |
| 11 | Il fader della Keystation muove la manopola VOLUME della postazione 1. Con FADER VOL spento non ha effetto sul volume. | |
| 12 | Tieni note su due tastiere con il pedale, cambia TRASP e premi PANIC: silenzio, nessuna nota appesa. | |
